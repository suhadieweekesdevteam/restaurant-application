## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- npm

### Installation
```bash
cd banjaraa-restaurant-app
npm install
```

### Run in Development
```bash
npm run dev
```

### Run Production Build & Preview
```bash
npm run build
npm run preview -- --port 4173 --host
```
Open **http://localhost:4173** in your web browser.
